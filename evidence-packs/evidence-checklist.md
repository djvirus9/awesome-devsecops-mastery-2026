# Evidence collection checklist

Assessment owner: [fill]. Scope/period/release: [fill]. Use the [index](evidence-index.md) and [control catalog](../templates/control-catalog.md).

- [ ] C01/C02: reviewed requirements/threat model and exact automated test results.
- [ ] C03/C04: merge settings, actual failed-check behavior, scanner reports and tool versions.
- [ ] C05/C06: released digest, schema-valid SBOM and signature/provenance verification against expected identity.
- [ ] C07: policy engine/version, scope, admitted/rejected fixtures and live admission result if claimed.
- [ ] C08/C09: authenticated local coverage, test limitations, redacted events and routing verification.
- [ ] C10/C11: tabletop record, follow-up owners, finding clocks and unexpired exception decisions.
- [ ] C12: metric population/formulas, source records and maturity assessment evidence.
- [ ] Every record has owner, UTC collection time, immutable reference, retention/access classification and reviewer.
- [ ] Any framework claim has exact framework version/control and a justified mapping.
- [ ] Missing, failed and stale evidence is visible; no release claim relies on illustrative records.
